# aep2026-2sem

Aplicação de console para cadastro de pacientes e registro de triagens. Na opção 6,
informe o ID do paciente, um ou mais sintomas, a intensidade de 1 a 10, a duração
em horas e observações. A opção 7 mostra o histórico do paciente.

Os dados ficam somente em memória e são apagados ao encerrar o programa. A
classificação de prioridade e o encaminhamento estão previstos para as próximas
sprints; esta versão não fornece diagnóstico nem orientação médica.

Requer Java 21 ou superior. Compile e execute a classe
`br.com.triagemcomunitaria.Main` pela IDE ou pelo Maven. O teste de domínio pode
ser executado com a classe `br.com.triagemcomunitaria.TriagemTest`.
